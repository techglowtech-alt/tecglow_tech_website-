# TECGLOW Tech & Creative Solutions Website

A responsive, single-page website built with HTML, CSS, and JavaScript. It is suitable for GitHub Pages static hosting.

## Files
- `index.html` — the complete website. Styles and JavaScript are included in this file.

## Publish on GitHub Pages
1. Create or open your GitHub repository.
2. Upload `index.html` to the repository's root (main page).
3. Commit the changes.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub Pages to publish and open the URL shown on the Pages screen.
